# EBG ProTrack — Sistema de Supervisión

Aplicación móvil PWA para supervisión de obras de construcción, desarrollada para **Engine Business Group**.

## 🚀 Inicio rápido

```bash
npm install --legacy-peer-deps
npm start
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 📦 Despliegue

```bash
npm run build
```

Genera la carpeta `build/` lista para Netlify.

## 📱 APK

Una vez desplegado en Netlify, usa [PWABuilder.com](https://www.pwabuilder.com) con la URL de Netlify para generar el APK de Android.

## 🛠 Tecnologías

- React 18 + TypeScript
- Recharts (gráficos)
- Create React App
- PWA (Progressive Web App)
